# TransperenC

**Redefining NGO Accountability through Real-Time Transparency**

TransperenC is a modern Android application designed to bridge the trust gap between Non-Profit Organizations (NGOs) and donors. By providing a live, verifiable financial ledger and real-time project reporting, we make philanthropy more accountable and transparent.

## Key Features

*   **Live Audited Ledger:** Real-time visualization of budget vs. actual spending for every project.
*   **NGO Compliance Score:** A dynamic metric that rates an NGO's transparency based on data completeness and financial health.
*   **Donor Portal:** A secure, intuitive interface for targeted contributions with simulated Section 18A tax certificate generation.
*   **Transparency Warriors (Gamification):** An XP and Leveling system that incentivizes NGOs to provide frequent, accurate reports.
*   **Statutory Deadline Alerts:** Proactive notifications for critical governance filings (e.g., SARS/IRS Form 990).

## Technical Stack

*   **Frontend:** Kotlin & Jetpack Compose (Material 3)
*   **Backend:** Firebase Firestore (Real-time NoSQL)
*   **Auth:** Firebase Authentication
*   **Architecture:** MVVM (Model-View-ViewModel)

## Future Roadmap

*   **Phase 2:** Integration of a true Blockchain ledger for immutable financial records.
*   **Phase 3:** Automated beneficiary verification via IoT and SMS gateways.
